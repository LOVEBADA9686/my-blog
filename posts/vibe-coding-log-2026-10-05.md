**작성: 2026-10-05 09:00 (KST)**

오늘은 보안 패치, 개인정보 옵트인, 그리고 놓치면 아까운 마감일까지 세 가지를 정리해봤다.

## 클로드 코드 2.1.289, 환경변수 뒤에 숨은 명령어까지 잡아내는 보안 패치

지난 10월 3일 공개된 클로드 코드 2.1.289는 27개의 CLI 변경사항을 담은 릴리스인데, 핵심은 보안 쪽 구멍 메우기다. 예를 들어 `TZ="$HOME" rm -rf build`처럼 환경변수 접두사 뒤에 위험한 명령어를 숨기거나, 샌드박스가 자동 허용하는 상황에서 단순 변수 할당 뒤에 명령어를 감추면 지금까지는 Bash deny/ask 규칙이 이를 놓치는 경우가 있었는데 이번 버전에서 고쳐졌다. IDE에서 심볼릭 링크로 연결된 파일이나 `@`로 멘션한 파일에도 Read deny 규칙이 제대로 적용되도록 범위를 넓혔고, 관리형 머신에서 복합 셸 명령어 중 일부에만 걸린 deny/ask 규칙이 사용자가 설치한 모드의 승인 때문에 무시되던 버그도 잡았다. 보안 패치 외에도 플러그인 팀원들이 `agent.spawn`으로 공유 에이전트를 띄울 수 있게 됐고, 짧은 코드 블록에 태그가 안 닫혔거나 중첩이 깊을 때 터미널이 멈추는 문제도 해결됐다. 권한 체크를 믿고 자동 모드로 돌리는 사용자가 늘어난 만큼, 이런 \"구멍 메우기\"형 패치가 꾸준히 나온다는 게 오히려 안심되는 지점이다.

## 앤트로픽, "음성 대화도 학습에 써도 될까요?" 옵트인 요청 시작

블리핑컴퓨터 보도에 따르면 앤트로픽이 클로드 음성 기능을 쓰는 사용자들에게 "AI 모델 개선을 위해 음성 데이터 사용을 허용해주세요"라는 안내를 새로 띄우기 시작했다. "허용" 또는 "지금은 안 함"을 고를 수 있고, 프라이버시 설정 안에 별도 토글도 있다. 기본값은 꺼짐이라 자동으로 동의 처리되는 사용자는 없고, 나중에 설정에서 끄거나 데이터를 삭제할 수도 있다고 한다. 중요한 건 이게 작년 8월부터 시행 중인 "일반 대화·코딩 세션 학습 활용" 옵트인과는 별개라는 점인데, 즉 일반 채팅은 학습 동의를 거부하면서 음성 대화만 허용하는 것도, 반대도 가능한 구조다. 옵션이 세분화되는 건 선택권이 넓어진다는 점에서 나쁘지 않지만, 토글이 하나씩 늘어날 때마다 "내가 지금 뭘 허용하고 있는지" 스스로 점검해볼 필요도 같이 늘어난다는 생각이 든다.

## 클로드 코드 클라우드 세션 크레딧(최대 250달러), 신청 마감 이틀 전

지난 9월 23일부터 시작된 프로모션인데, 당시 활성 구독자였던 프로·맥스 개인 사용자에게 클라우드 세션용 프로모션 크레딧을 준다. 프로는 100달러, 맥스는 250달러 규모다. 클로드 웹사이트에서 10월 7일까지 신청해야 하고, 받은 크레딧은 11월 4일에 잔액과 상관없이 소멸된다. 클라우드 세션은 앤트로픽이 호스팅하는 인프라에서 돌아가기 때문에 내 컴퓨터를 꺼둬도 작업이 계속 진행된다는 장점이 있는데, 아직 신청을 안 한 맥스·프로 구독자라면 이틀 안에 챙겨두는 게 좋을 것 같다.

## 오늘의 생각

보안 패치는 "이미 쓰고 있는 기능을 더 안전하게", 음성 학습 옵트인은 "새로운 데이터 영역에 대한 동의 범위를 넓히는" 방향이고, 크레딧 마감은 그냥 "지금 안 챙기면 사라지는" 실용적인 이야기다. 세 소식의 결이 다 다르지만 공통점이 하나 있다면, 바이브코딩 도구를 쓰는 입장에서 설정 화면과 공지 메일을 주기적으로 들여다봐야 할 이유가 계속 늘어나고 있다는 점이다. 자동화가 편해질수록 그 뒤에서 바뀌는 디테일을 챙기는 건 여전히 사람의 몫인 셈이다.
